# Reusable LFM d1 decisions

`candle_vlm::lfm2_d1` adds local, non-generative System One decisions to the
existing LFM2-VL hybrid model. The library has no consumer application dependency
and performs no network access. The original d1 source checkpoint extends base
`313a1cd9166b8db5abfb9420d0780ac1f7fd925f`. The owner authorized scoped Candle
publication on 2026-10-08; its exact published identity is owned by the guarded
publication receipt described below. Numerical proof retains its measured source.

## API contract

- `Question::{Noul, Choice, Score}` and corresponding `Answer` variants are typed.
  `OrderedMap<T>` preserves JSON object order and rejects duplicate keys.
  `State` supports text, null and ordered structured JSON. Scores require 2–10
  ordered rubric levels. Choice descriptions may be null or empty.
- `load_d1_q8(D1LoadOptions { hybrid, limits })` takes the existing explicit local
  hybrid paths/devices, requires Q8 MMProj/F32 activations and rejects forced
  dequantization. `D1Session::from_hybrid(loaded, D1PolicyV1, limits)` validates an
  existing hybrid model's retained Q8 storage. Active text LoRA is rejected.
- `session.prepare(&request, image_count)` exposes ordered question plans,
  rendered prompts and token groups. `PreparedQuestion::token_groups()` and
  `question_text()` are immutable views. `session.decide(&request, &images)`
  returns ordered answers, actual usage, dispatch counts and unattempted counts.
  `consumed_files()` returns the loader's exact file-path inventory;
  `execution_details()` reports storage/device admission before inference.
- `decide_with_cancel` checks cancellation between synchronous forwards.
  `decide_traced` additionally exposes borrowed processor tensors, immutable image
  features, question IDs/prompts and final vocabulary logits for requested proof.
  `DecisionFailure` contains a message, optional question index and boxed partial
  response. Completed answers survive later failure. Caches clear on return.
- `decide_traced_profiled` fills `D1Timings` with synchronized phase durations,
  including attempted phases on failure. Profiling is opt-in; existing methods
  and trace variants remain stable. Trace observation is measured separately.
- Each question gets an independent fresh prefill. Optional images are converted
  to RGB, capped to 1,048,576 pixels with the reference bicubic policy, processed
  and encoded once per request. The same immutable features serve all questions.
  Prompts exceeding the configured/model context fail before any model forward.
  Output tokens are always zero. Input usage sums independently expanded prompts.

The caller owns resource admission, process isolation, deadlines, file identity
admission and study orchestration. Cancellation does not interrupt a running
synchronous forward. CPU builds require no CUDA libraries; the optional `cuda`
feature forwards Candle's existing CUDA features. CPU/CUDA F32 are the supported
device contracts; current qualification limitations are stated below.

## Pinned policy and native weight mix

`D1PolicyV1` pins `lfm-d1-systemone-v1`: no system turn, `json_only` state,
description option lines, empty assistant lead and identity calibration. The
official `LiquidAI/d1-3B` policy revision is
`051bcc464b01b9f92942b364d9586b0ef5912432`. Exact source/model/projector/tokenizer/
processor/template identities are in
[`reference-lock.json`](../../tools/lfm2_vl/d1/reference-lock.json).

Noul max-pools deduplicated yes/Yes/YES and no/No/NO token aliases and returns
P(yes). Choice preserves reference option order, assigns distinct single-token
codes with the official fallback pool, and includes leading-space aliases.
Score returns the expected rubric index. Readout validates the complete F32
vocabulary, max-pools raw aliases and normalizes option scores in F64. The shared
vocabulary log-normalizer cancels from this option normalization. Ties keep
the first reference option. `candle_transformers::models::lfm2_d1` owns this
tensor primitive; `candle-vlm` owns tokenizer and rendering behavior.

The exact retained d1 Q8 text model has 167 major quantized linears. Its
projector contains 137 native Q8 tensors and 27 original F16 feed-forward down
matrices whose input width is 4304. The owner explicitly selected preservation
of that mix. Every Q8 matrix remains quantized; those original floating matrices,
embedding lookup, biases and normalizations use F32 computation. No padded or
requantized derivative is produced. Floating linear names are reported.

Quantized projector inputs are made contiguous, flattened to checked matrix rows,
multiplied natively and reshaped to the exact original leading dimensions.
The call-scoped `candle::quantized::with_native_q8_0` guard rejects dense QMatMul,
non-Q8 weights, non-F32 inputs and forced CUDA dense execution. CPU dots read
retained Q8 blocks directly into F32 arithmetic (AVX2/FMA when available, with a
portable scalar path). CUDA uses an explicit F32/Q8 kernel. Neither path
requantizes activations or allocates a dense copy of Q8 linear weights. Dispatch
receipts report `cpu_q8_matmuls` or `cuda_f32_q8`; the older CUDA MMVQ/MMQ counters
stay zero in this strict policy. Ordinary callers retain their execution policy.
